# srcplugins

**Focused plugins with published source code.**

We build plugins that make the software you already use more useful. Every plugin has a public source repository, so you can inspect its code, permissions, and behavior.

[Website](https://srcplugins.com/) · [Atlassian Marketplace](https://marketplace.atlassian.com/vendors/651695956/)
